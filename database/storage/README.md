# AgencyOS — Zoho Catalyst Stratus Storage

**Service:** Zoho Catalyst Stratus (Object Storage)  
**Purpose:** Storing client uploaded assets, branding kits, website export bundles, and generated proposal PDF documents.

---

## 1. Storage Buckets
* `agencyos-client-assets` — Client uploaded logos, images, documents.
* `agencyos-proposals` — Generated PDF scopes of work and contracts.
* `agencyos-audit-reports` — Exported website performance audit reports.
